# 토질 틈틈봇

토질및기초기술사 — 낭독본의 **【살】을 인출 카드로** 바꿔 틈틈이 꺼내 쓰는 앱.
PMP 틈틈봇과 같은 방식이되, **학습과학 근거**에 맞춰 반복 주기를 설계했다.

현재 수록: **제1장 흙의 성질 · 139장**
공식 27 · 그림 20(그리기 10 + 알아보기 10) · 살 35 · 수치 14 · 인출 18 · 답안골격 11 · 비교표 9 · 분류기준 5

---

## 왜 이렇게 만들었나 — 설계 근거

| 장치 | 근거 |
|---|---|
| **질문 → 내가 누를 때 답** | 인출 연습이 반복 읽기를 크게 앞선다 (Karpicke & Roediger, *Science* 2008 — 1주 뒤 80% vs 36%). 답을 먼저 보여주면 인출이 아니라 재독이 된다. 대기 시간을 강제하지 않는 대신, **떠올린 다음에 누르는 것**이 규칙이다 |
| **간격 1 → 3 → 7 → 21일** | 분산연습. **24시간 뒤 첫 복습이 가장 중요**하다. 첫 간격을 3일로 두면 이미 늦다 |
| **직전과 다른 절에서 뽑기** | 교차연습. 블록으로 몰아 풀면 연습 중엔 잘 되지만 시험에서 무너진다 (Rohrer 외 2020, 787명 RCT, **d = 0.83**) |
| **자가평가 3단계** (막힘없이 / 겨우 / 못 함) | **유창성 착각** 차단. "겨우 떠올림"은 간격을 늘리지 않는다. 읽으면 아는 것 같은 느낌을 안다고 세지 않기 위함 |
| **공식은 좌변 → 우변** |  를 묻고  를 답한다. "이 식은 어디에 쓰나"는 답이 모호해 자가채점이 안 된다. 시험에서 필요한 것도 우변을 꺼내는 쪽이다 |
| **그림은 양방향** | 이름 → 그리기, 그림 → 무엇인지. 작도는 두 방향을 다 요구한다 |
| **수치 빈칸** | 값만 ◻︎로 가린다. Cu ≥ 4인지 6인지, #200 통과 35%인지 50%인지 — 실제로 갈리는 자리만 |
| **21일까지 통과해야 완료** | 한 번 맞혔다고 끝내지 않는다 |

Dunlosky 외(2013)가 10개 학습기법을 등급화했을 때 **고효용은 연습시험과 분산연습 둘뿐**이었다.
이 앱은 그 둘만 한다. 다시 읽기·형광펜·요약은 저효용이라 넣지 않았다.

## 쓰는 법

**① 폰 — 잠금화면 (핵심)**
- APK 설치 → 권한 2개 허용 → 화면 켤 때마다 카드가 뜬다

**② PC — 바탕화면 앱**
- PC(Chrome·Edge): 페이지 열고 주소창 오른쪽 **설치** 아이콘 → 바탕화면 아이콘 생성
- 폰: 공유 → **홈 화면에 추가**
- 설치하면 오프라인에서도 열린다(Service Worker)

**그림** — 그림을 누르면 전체화면으로 커진다. ＋/− 버튼과 두 손가락 핀치로 확대, 스크롤로 이동, 닫기(또는 Esc)로 복귀.

**단축키** — `Space` 답 보기 · `1` 막힘없이 · `2` 겨우 · `3` 못 함 · `N` 건너뛰기

**필터** — 하단에서 태그(인출·살·골격·비교표·갭B)와 절을 고른다.
학습 기록은 브라우저에 저장되므로 **PC와 폰이 따로** 쌓인다.

## 카드는 어디서 오나

낭독본 HTML에서 자동 추출한다. 손으로 옮겨 적지 않는다.

```
차량학습_이론서/01_흙의성질.html
        │  .rc  (인출 프롬프트)   →  recall 카드
        │  .fx  (수식)            →  formula (좌변 → 우변)
        │  <figure> (SVG)         →  figure + figure_id (양방향)
        │  .fx  (분류 규칙표)     →  rule 카드
        │  .sal 안의 <b> + 수치   →  number 카드
        │  .sal / .skel / .gapb   →  sal · answer 카드
        │  <table>                →  table 카드
        ▼
   _빌더/build_cards.py  →  cards.json
   _빌더/build_app.py    →  index.html (카드 내장)
```

**낭독본을 고치면 카드도 따라 바뀐다.** 두 곳을 따로 관리하지 않는다.

## 수정하고 배포하기

```bash
# 1) 낭독본을 고쳤다면 카드부터 다시 뽑는다
cd _빌더
python -X utf8 build_cards.py     # cards.json 갱신
python -X utf8 build_app.py       # 토질_틈틈봇.html 갱신

# 2) index.html 재생성 (PWA 태그 + SW 등록 주입)
cd ..
python -X utf8 _빌더/make_index.py

# 3) 푸시하면 GitHub Pages가 자동 배포된다
git add -A && git commit -m "1장 카드 갱신" && git push
```

`.github/workflows/deploy.yml` 이 push마다 Pages에 올린다.
Service Worker는 **네트워크 우선**이라 푸시 직후 새로고침하면 최신본이 뜬다.
캐시가 남으면 `sw.js` 의 `VER` 값을 올린다.

## 안드로이드 — 잠금화면 학습

휴대폰 **화면을 켤 때마다** 카드 한 장이 잠금화면 위에 뜬다. 이게 틈틈봇의 핵심이다.

- **OverlayService** — 포그라운드 서비스, `SCREEN_ON` 감지 (최소 간격 60초)
- **LockScreenActivity** — `showWhenLocked`·`turnScreenOn`, 잠금화면 위 WebView 카드
- **BootReceiver** — 재부팅 후 자동 재시작
- **TTS 브리지** — 카드가 뜨면 **질문을 읽어준다**. 답을 보면 멈춘다. 운전 중·손 못 쓸 때도 인출이 걸린다

**설치 후 권한 두 개**를 반드시 켠다 — `다른 앱 위에 표시`(오버레이), `알림`.
둘 다 켜야 화면 켤 때 카드가 뜬다.

APK 받기: Actions 탭 → **Build APK** → Artifacts → `toji-tteum-debug-apk`
